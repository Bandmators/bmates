`BMates` is the quickest way to mount the Canvas editor and a React track list. It creates the `Editor`, keeps track
state synchronized, and releases browser resources when the component unmounts.

## Convenient component

```tsx
import { BMates, BmatesProvider, type TrackDataType } from '@bmates/studio';

const tracks: TrackDataType[] = [];

export const AudioEditor = () => (
  <BmatesProvider>
    <BMates
      data={tracks}
      onError={error => console.error(error)}
      trackEl={({ muted, removeTrack, toggleMute, track }) => (
        <div>
          <strong>{track.name}</strong>
          <button onClick={toggleMute}>{muted ? 'Unmute' : 'Mute'}</button>
          <button onClick={removeTrack}>Remove</button>
        </div>
      )}
    />
  </BmatesProvider>
);
```

### Props

| Prop      | Type                                  | Description                                  |
| --------- | ------------------------------------- | -------------------------------------------- |
| `data`    | `TrackDataType[]`                     | Initial tracks and clips.                    |
| `style`   | `EditorStyleType`                     | Optional partial editor style configuration. |
| `trackEl` | `(props: TrackProps) => ReactElement` | Optional renderer for each track row.        |
| `onError` | `(error: Error) => void`              | Reports loading or editor startup failures.  |

Use `useBMates` inside `BmatesProvider` when you need the legacy transport and file commands exposed by the
convenient component.

## Composable editor

For custom layouts, use the compound components. They share one store, so the track list, Canvas, controls, and
external subscribers observe the same project state.

```tsx
import { BMates, useBMatesSelector, useBMatesStore } from '@bmates/studio';

const Transport = () => {
  const store = useBMatesStore();
  const isPlaying = useBMatesSelector(snapshot => snapshot.isPlaying);

  return (
    <button onClick={() => void (isPlaying ? store.pause() : store.play())}>{isPlaying ? 'Pause' : 'Play'}</button>
  );
};

export const CustomAudioEditor = () => (
  <BMates.Root defaultData={tracks} onDataChange={project => saveProject(project)}>
    <Transport />
    <BMates.TrackList>
      {({ muted, remove, toggleMute, track }) => (
        <div>
          <span>{track.name}</span>
          <button onClick={toggleMute}>{muted ? 'Unmute' : 'Mute'}</button>
          <button onClick={remove}>Remove</button>
        </div>
      )}
    </BMates.TrackList>
    <BMates.Canvas aria-label="Audio timeline" />
  </BMates.Root>
);
```

Use `defaultData` for editor-owned state. Use the controlled `project` prop only when the application intentionally
owns the complete project and updates it from `onDataChange`.

## Declarative project

Tracks and clips can also be declared as React components. Do not combine `BMates.Root project` with
`BMates.Project`; choose one project ownership model.

```tsx
<BMates.Root>
  <BMates.Project>
    <BMates.Track id="vocals" name="Vocals">
      <BMates.Clip id="lead" src="/audio/lead.wav" start={0} />
    </BMates.Track>
  </BMates.Project>
  <BMates.Canvas />
</BMates.Root>
```

See [useBMates](/docs/usebmates) for the convenient component hook and [Lifecycle and cleanup](/docs/guides/lifecycle)
for ownership rules.
