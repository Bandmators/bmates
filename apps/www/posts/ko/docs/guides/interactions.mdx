Canvas 타임라인은 클립 선택과 드래그를 처리합니다. 기본 클릭은 wave를 선택하고, Shift를 누른 채 클릭하면 선택에 추가합니다.
선택한 클립은 가로 또는 다른 트랙으로 드래그할 수 있습니다. 잠긴 클립은 이동하지 않으며 충돌 검사가 잘못된 겹침을 막습니다.

| 단축키                                     | 동작                                 |
| ------------------------------------------ | ------------------------------------ |
| `Ctrl/Cmd + Z`                             | 실행 취소                            |
| `Ctrl/Cmd + Shift + Z` 또는 `Ctrl/Cmd + Y` | 다시 실행                            |
| `Ctrl/Cmd + C`, `X`, `V`                   | 선택한 클립 복사, 잘라내기, 붙여넣기 |
| `Delete` 또는 `Backspace`                  | 선택한 클립 제거                     |
| 화살표 키                                  | 선택한 클립 미세 이동                |

단축키를 사용하기 전 Canvas에 포커스를 주세요. React에서는 `useBMatesStore`로 명령을 실행하고
`useBMatesSelector`로 렌더링 상태를 읽으세요.
