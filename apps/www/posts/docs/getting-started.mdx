## Installation

BMates is available as a package on NPM for use:

```shell
# NPM
npm install @bmates/studio
```

## Create Component

Please import the BMates component.

```tsx
import { BMates } from '@bmates/studio';
```

Set the appropriate props for the BMates component.

```tsx
const App = () => {
  const editorRef = useRef<Editor | null>(null);

  return (
    <BmatesProvider editorRef={editorRef}>
      <ControlPanel />
      <BMates
        data={data}
        style={style}
        trackEl={({ track, muted, toggleMute, removeTrack }) => {
          return (
            <div className="track">
              <div className="name">{track.name}</div>
              <div className="feature">
                <ToggleMute muted={muted} onClick={toggleMute} />
                <RemoveTrackButton onClick={removeTrack}>Remove</RemoveTrackButton>
              </div>
            </div>
          );
        }}
      />
    </BmatesProvider>
  );
};
```

And feel free to manage it using the `useBMates` hook.

```tsx
const ControlPanel = () => {
  const { isPlaying, togglePlay, toggleStopPlay, handleFileUpload, download, editorRef } = useBMates();

  return (
    <div>
      <Button variant="primary" onClick={togglePlay}>
        {isPlaying ? 'Pause' : 'Play'}
      </Button>
      <Button variant="primary" onClick={toggleStopPlay}>
        Stop
      </Button>
      <input type="file" accept="audio/*" onChange={handleFileUpload} />
      <Button variant="primary" onClick={download}>
        Download
      </Button>
      <Button
        variant="primary"
        onClick={() => {
          console.log('Result: ', editorRef.current.export());
        }}
      >
        Export
      </Button>
    </div>
  );
};
```

Other frameworks besides React are currently in preparation.

The `style` and `trackEl` props are optional. BMates applies its default theme and a
track-name renderer when they are omitted. Use `onError` to surface audio loading or
decoding failures in your application.

## Composable editor UI

Use the compound API when your application needs custom layout and controls without directly managing an `Editor` ref.
The React track list and Canvas timeline subscribe to the same store.

```tsx
import { BMates, useBMatesSelector, useBMatesStore } from '@bmates/studio';

const Transport = () => {
  const editor = useBMatesStore();
  const playing = useBMatesSelector(state => state.isPlaying);

  return <button onClick={() => void editor.togglePlayback()}>{playing ? 'Pause' : 'Play'}</button>;
};

const CustomEditor = () => (
  <BMates.Root defaultData={data} onDataChange={saveProject}>
    <Transport />
    <div style={{ display: 'flex', height: 600 }}>
      <BMates.TrackList>
        {({ track, muted, toggleMute }) => (
          <button onClick={toggleMute}>{muted ? `Unmute ${track.name}` : `Mute ${track.name}`}</button>
        )}
      </BMates.TrackList>
      <BMates.Canvas style={{ flex: 1 }} />
    </div>
  </BMates.Root>
);
```

`defaultData` initializes an uncontrolled editor. For integration outside the React tree, create a store with
`createBMatesStore` and pass it to `BMates.Root` through the `store` prop.

The project source of truth is the framework-independent `@bmates/core` store. Plugins and non-React integrations can
share it with Studio:

```tsx
import { createProjectStore } from '@bmates/core';
import { BMates, createBMatesStore } from '@bmates/studio';

const projectStore = createProjectStore(data);
const studioStore = createBMatesStore({ projectStore });

<BMates.Root store={studioStore}>
  <BMates.Canvas />
</BMates.Root>;
```

Project export and undo/redo work headlessly. Playback and audio import/export require the mounted Canvas/Web Audio
adapter.

Use `project={project}` together with `onDataChange` for a controlled editor. Do not combine the controlled `project`
prop with a `BMates.Project` component tree; each is a complete declarative owner.

### Declarative tracks and clips

Tracks and clips can be expressed directly as React components. The editor reconciles component mount, prop updates,
and unmount by ID without recreating unchanged audio resources.

```tsx
<BMates.Root>
  <BMates.Project>
    <BMates.Track id={'drums'} name={'Drums'}>
      <BMates.Clip id={'kick'} src={'/kick.wav'} start={0} instrument={'Kick'} />
      <BMates.Clip id={'snare'} src={'/snare.wav'} start={1} instrument={'Snare'} />
    </BMates.Track>
  </BMates.Project>

  <BMates.Canvas />
</BMates.Root>
```

IDs must be unique within a project. User interactions continue to emit `onDataChange`; update the declared props from
that callback when the React tree should remain fully controlled.

Use `useBMatesTrack(id)` and `useBMatesClip(id)` to build UI that subscribes to one editor entity.

## Framework

`@bmates/studio` is the React adapter. Use `@bmates/core` for framework-independent state and commands, and add
`@bmates/editor` for Canvas rendering and Web Audio.

```shell
# NPM
npm install @bmates/core @bmates/editor
```

We will support other frameworks soon.
